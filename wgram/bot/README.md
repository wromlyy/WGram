# Бот профилей WGram для BotHost

Публичная группа не нужна. Бот принимает фото в личных сообщениях;
профили и значки выдаёт подключённым клиентам через HTTPS API.
Обычный Telegram не отображает баннеры и награды WGram в профилях.
Метаданные доступны всем авторизованным пользователям сервиса; это не
секретное хранилище от технически подготовленного пользователя.

1. В @BotFather создай бота. Токен добавь только в переменную `BOT_TOKEN` в BotHost.
2. Загрузи содержимое этой папки. Главный файл: `bot.py`, Python 3.11+.
   Включи «Использовать собственный Dockerfile». Для ZIP-загрузки включи
   «Загрузка бота из архива» в профиле BotHost. По документации BotHost
   загрузка архивов доступна на Базовом/Pro и пока ограничена тестовой нодой:
   [инструкция загрузки](https://bothost.ru/docs/upload-bot-archive).
   При использовании приватного Git-репозитория сначала настрой доступ BotHost к нему.
3. Выдели постоянное хранилище для `WGRAM_DATA_DIR` (например `/app/data`).
   В нём SQLite с профилями, баннерами, значками и хешами временных сессий.
   Без постоянного диска пересоздание контейнера потеряет данные.
4. Укажи `PORT=3000`, подключи HTTPS-домен к этому порту. API без HTTPS в моде не принимается.
5. В WGram открой подключение сервиса и введи HTTPS-адрес. Нажми подключить,
   затем отправь стартовую команду боту. Пароли, SMS-коды и API hash боту не нужны.
6. Публикуй оформление из WGram или отправь фото боту в личку.
   Значки выдаёт только пользователь 8226881959.

Проверка отправителя выполняется по Telegram `from.id`, только в личной переписке;
пересланные команды не принимаются. Одноразовая привязка действует 5 минут,
сессия клиента — 30 дней; токены хранятся в БД только как SHA-256.
Чужой ID в JSON не позволяет менять чужой профиль. Сервис не имеет доступа
к чьей-либо сессии Telegram, личным чатам и кодам входа.

Фото, отправленное боту, доступно Telegram и оператору хостинга.
Публикация добровольная. Удаление оформления из приложения удаляет запись
и баннер из сервиса; копии уже отправленных сообщений боту нужно удалить в Telegram отдельно.
База и её резервные копии содержат пользовательские данные — доступ к диску должен быть закрыт.

Документация BotHost: [переменные](https://bothost.ru/docs/environment-variables),
[домен и порт](https://bothost.ru/docs/domains-and-ports),
[база в /app/data](https://bothost.ru/docs/database-storage).

Запуск тестов: `python -m unittest discover -s tests -v`.
