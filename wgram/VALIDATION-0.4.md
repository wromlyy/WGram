## Что проверено

Оба запуска: Android 14 / API 34, офлайн-эмулятор, полное оформление,
программный GPU Lavapipe. Каждый дал `WGRAM_SMOKE_OK: 76 screens and behavior checks passed`.
В первом прогоне системный Pixel Launcher завис поверх части скриншотов.
В повторе лаунчер отключён в пустой тестовой среде; приложение и тестовый APK
использованы без пересборки. Изменение тестового окружения: `037a909`.

Проверены 28 экранов, логика истории SQLite и спаны эмодзи, прежние профили
и награды, новые разделы настроек, неподключённый каталог, карточка эмодзи
при `isPremium=false`, реальный Python runtime, загрузка/выгрузка плагина,
обработка отправки и исключение секретных чатов. Редактор открывает рабочий
шаблон, сохраняет и восстанавливает Unicode-черновик; мост сохранения
не запускает обновлённый код и оставляет плагин выключенным.

Вне Android прошли **170** проверок поведения: 125 Java, 18 Python-плагинов
и редактора, 27 HTTP/SQLite/бота. Дополнительно разобран синтаксис 58 Java-файлов,
проверены 255 используемых строк WGram и 28 XML. Bot API в тестах замокан;
проверены как native entity, так и отказ/удаление entity с реальным PNG fallback.

## Границы проверки

Сервис и Telegram-группа не развёрнуты. Живые отправки ботом, обмен эмодзи
между двумя аккаунтами, вход в Telegram, сетевое применение каталога и поведение
призрака в реальных чатах не проверены. Android-прогон карточки проверяет
создание renderer без Premium и его lifecycle; он не скачивает анимацию
из Telegram, поскольку сеть эмулятора заблокирована.

Эта сборка реализует WGram API 1, а не весь SDK exteraGram. Полная эквивалентность
AyuGram/exteraGram отсутствует; список оставшихся функций — в [FEATURES-0.4.md](FEATURES-0.4.md).
Firebase push выключен в этой тестовой сборке; фоновые уведомления могут задерживаться.
Плагины выполняют доверенный код с правами приложения. Данные тестовых аккаунтов
не использовались для входа в Telegram; тесты работают в пустом эмуляторе.
