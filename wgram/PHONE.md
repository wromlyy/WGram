# WGram с телефона

Рабочий репозиторий: https://github.com/wromlyy/WGram, ветка `wgram`.
Репозиторий приватный: для просмотра и скачивания Actions нужен вход
в аккаунт с доступом к нему. Создавать новый fork не требуется.

## Установка

Ссылка на актуальный APK находится в [README](../README.md).
Артефакт GitHub Actions — ZIP: распакуйте его и откройте `app.apk`.
Можно также открыть файл `~/WGram.apk` в Termux после загрузки сборки.
Android может попросить разрешить установку из выбранного приложения.

Пакет `org.wgram.messenger.beta` устанавливается рядом с Telegram.
Для обновления WGram используйте APK с тем же сертификатом WGram Development;
тогда установленное приложение и данные аккаунтов сохраняются.
Исходные коды лежат в `~/WGram`, компьютер для сборки не нужен.

## Первое включение общего оформления

1. Войдите в WGram через Telegram. API ID приложения не является ID пользователя.
2. Владелец **8226881959** открывает **Настройки WGram → Админка → Создать каталог**.
3. Пользователь открывает свой профиль → **Настроить профиль WGram**.
4. Выбирает баннер и статус, нажимает **Опубликовать оформление** и подтверждает
   публикацию в публичной Telegram-группе.
5. Другой WGram открывает профиль и нажимает **Обновить оформление WGram**.

Для уведомления админ открывает профиль получателя → **Админка**, выбирает
тип, причину и срок, затем проверяет получателя и нажимает **Отправить**.
Для значка задаёт название, описание и эмодзи и нажимает **Выдать значок**.
Каталог для значков должен быть создан. В других аккаунтах отправка недоступна.

История сообщений и все переключатели призрака включаются отдельно.
Подробное поведение и ограничения: [WGram 0.2](FEATURES-0.2.md).

## Новая сборка

В репозитории откройте **Actions → WGram debug APK → Run workflow**,
выберите ветку `wgram`. API-параметры и ключ подписи уже настроены в Secrets.

`reuse_native` сокращает сборку: берёт native-библиотеки из известного APK
после проверки SHA-256 и неизменности дерева JNI. Java, ресурсы и приложение
собираются заново. Если JNI изменилось или исходный артефакт истёк,
выключите этот параметр для полной сборки. Исходный артефакт хранится ограниченное
время, поэтому этот режим не заменяет возможность собрать исходники полностью.

Успешный запуск содержит **Artifacts → WGram-debug**. Скачайте ZIP.
В приватном репозитории сборки расходуют лимит GitHub Actions аккаунта.
Firebase в тестовой конфигурации выключен: фоновые уведомления могут задерживаться.
