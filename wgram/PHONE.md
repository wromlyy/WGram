# WGram с телефона

Репозиторий: https://github.com/wromlyy/WGram, ветка `wgram`.
Он приватный: нужен вход в GitHub с доступом к нему.

## Установка

WGram 0.3 пока проходит проверку запуска.
Ссылка на проверенную сборку будет добавлена после её завершения.
Не устанавливайте **Source code (zip)**: это исходники, а не приложение.
Для установки нужен отдельный файл **WGram.apk**, распаковка не требуется.

Готовый APK также сохраняется в `~/WGram.apk`. В Termux его можно открыть:

```sh
termux-open --view --content-type application/vnd.android.package-archive ~/WGram.apk
```

Android может попросить разрешить установку из выбранного приложения.
Пакет `org.wgram.messenger.beta` устанавливается рядом с Telegram.
Подпись WGram сохраняется между версиями: обновление устанавливается поверх
предыдущего WGram с сохранением данных.

## Подключение бота вместо публичной группы

1. Создай бота в @BotFather, затем загрузи
   [WGramBot.zip](https://github.com/wromlyy/WGram/releases/download/bot-v0.1/WGramBot.zip)
   на BotHost по [инструкции](bot/README.md).
2. Добавь `BOT_TOKEN` в переменные хостинга, включи постоянное хранилище,
   подключи HTTPS-домен к порту сервиса. Токен в APK вводить не нужно.
3. В профиле открой **WGram → Настроить профиль WGram → подключение сервиса**,
   введи HTTPS-адрес, нажми подключить и подтверди привязку в личке с ботом.
4. Выбери оформление и нажми **Опубликовать оформление**.
   Баннер также можно отправить боту фотографией в личные сообщения.
5. Другой подключённый WGram получает значки в списке чатов и заголовке личного чата.
   Баннер загружается при открытии профиля. Для повторной загрузки открой
   **WGram → Обновить оформление WGram** в профиле.

Бот пока не запущен автоматически: для работы нужен настроенный хостинг.
Обычный Telegram не отображает баннеры и значки WGram в профиле.

## Админка, история и копирование

Администратор **8226881959** открывает админку в настройках WGram
или в профиле получателя. Блоки раскрываются на одном экране:
уведомления, ограничение до отзыва, значки, шаблоны и журнал.
Администратор может выдать до трёх значков рядом и снять выбранный значок отдельно.
Для общих значков требуется подключение к боту.
Текст ограничения можно изменить; снять его может администратор.
Ограничение относится к клиенту WGram и не блокирует аккаунт Telegram.

История включается отдельно в **Настройки WGram → Сообщения и приватность**.
Полученный после включения обычный текст остаётся в чате после удаления
с отметкой ×. Предыдущие правки доступны в истории.
Призрак имеет четыре независимых переключателя.

В меню личного чата доступно **Скопировать профиль**.
После подтверждения меняются реальные имя, фото и описание своего Telegram;
оформление WGram копируется локально. Username и награды не копируются.
[Подробные ограничения](FEATURES-0.3.md).

## Новая сборка

В GitHub открой **Actions → WGram debug APK → Run workflow**,
выбери ветку `wgram`, включи **run_ui_smoke** для проверки экранов.
API-параметры и постоянный ключ подписи настроены в Secrets.
`reuse_native` использует проверенные native-библиотеки при неизменном JNI;
Java, ресурсы и приложение собираются заново.

Артефакт **WGram-debug** содержит APK. Его наличие ещё не означает,
что последующая проверка запуска прошла: дождись успешного результата workflow.
Готовый релиз предоставляет APK отдельно от ZIP.
Firebase выключен: фоновые уведомления могут задерживаться.
