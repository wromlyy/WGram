# WGram: первая сборка с Android-телефона

Компьютер не нужен: исходники уже находятся в `~/WGram`,
а сборка выполняется на GitHub Actions.
[Готовая тестовая APK в ZIP](https://github.com/wromlyy/WGram/actions/runs/40206752484/artifacts/12603569560).
Для скачивания нужен вход в GitHub. Если нужен только APK,
скачайте и распакуйте этот архив; команды ниже нужны для своей сборки.
Команды ниже ещё не выполнялись: они публикуют исходники в вашем аккаунте.
Проходите шаги по очереди; при ошибке остановитесь и сохраните её текст.

## 1. Аккаунт GitHub

Откройте https://github.com/signup в браузере и создайте аккаунт.
Подтвердите почту. Пароль и коды входа вводите только на сайте GitHub.

## 2. Параметры Telegram

Откройте https://my.telegram.org и войдите со своим номером Telegram.
Выберите **API development tools** и зарегистрируйте Android-приложение:
название `WGram`, короткое имя, например `wgramandroid`.
Сохраните выданные `api_id` и `api_hash` у себя. Их нужно будет ввести
в GitHub Secrets; в чат или публичные исходники их вставлять не нужно.

Официальная инструкция: https://core.telegram.org/api/obtaining_api_id.
Если сайт выдаёт ошибку, сначала решите её; чужие параметры не подставляйте.

## 3. Вход в GitHub из Termux

В приложении Termux выполните:

```sh
pkg install gh
cd ~/WGram
gh auth login --hostname github.com --git-protocol https --web --scopes workflow
gh auth setup-git
```

Следуйте подсказкам: откройте страницу GitHub в браузере и введите
показанный код устройства. Код и пароль не нужно отправлять в чат.
Если телефон не открывает браузер автоматически, откройте показанную
ссылку вручную. Для этих команд нужен интернет.

## 4. Публикация исходников в свой fork

Следующие команды создадут **публичную** копию Telegram под именем WGram,
сохранят изменения и загрузят ветку `wgram`. Исходный Telegram не изменится.
Если у вас уже есть репозиторий WGram или ветка wgram, эти команды нужно
адаптировать к существующему репозиторию.

```sh
cd ~/WGram
gh repo fork DrKLO/Telegram --fork-name WGram --clone=false --remote=false
wgram_owner=$(gh api user --jq .login)
git switch -c wgram
git add .
git -c user.name=WGram -c user.email=wgram@localhost commit -m "Add WGram Android customization"
git remote add wgram "https://github.com/$wgram_owner/WGram.git"
git push wgram HEAD:wgram
gh repo edit "$wgram_owner/WGram" --default-branch wgram
```

Ветка wgram становится основной, чтобы GitHub показывал подготовленную
ручную сборку. Загрузка использует уже существующую историю fork;
вручную добавлять тысячи файлов через браузер не нужно.

## 5. Секреты и запуск

В браузере откройте свой репозиторий WGram. Если мобильный сайт скрывает
настройки, включите в меню браузера «Версия для ПК».

Откройте **Settings → Secrets and variables → Actions → New repository secret**.
Создайте два секрета:

- `WGRAM_API_ID` — значение api_id;
- `WGRAM_API_HASH` — значение api_hash.

Firebase для первой сборки не требуется. В этой сборке отключены Google
push-уведомления: в фоне уведомления могут задерживаться или не приходить.

Откройте **Actions**. Для fork GitHub может предложить включить workflows.
Выберите **WGram debug APK → Run workflow → ветка wgram → Run workflow**.
Первый запуск скачает Android-инструменты и native-зависимости.
Проверенная универсальная сборка заняла около 34 минут;
время следующих запусков может отличаться.

## 6. APK

Дождитесь успешного завершения. Откройте запуск и раздел **Artifacts**,
скачайте `WGram-debug`, распакуйте ZIP и откройте `app.apk` на телефоне.
Android может запросить разрешение на установку из этого приложения.
WGram устанавливается отдельно от официального Telegram.

Если сборка красная, откройте упавший шаг и сохраните текст ошибки:
скачивать APK будет возможно только после её исправления.

Это debug-сборка для проверки. Для обновления APK без переустановки workflow поддерживает
секрет `WGRAM_DEBUG_KEYSTORE_BASE64` с постоянным ключом разработки.
Без этого секрета ключ может меняться между запусками. Релизная подпись
для распространения настраивается отдельно. Обмен WGram-эмодзи и внешний вид ещё нужно проверить
на реальных устройствах; оформление профиля пока локальное.

GitHub: [скачивание artifacts](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/download-workflow-artifacts).
