# WGram 0.4 — плагины и настройки

Рабочая ветка: `wgram-0.4-plugins`. Это первый этап расширения WGram;
полный набор возможностей exteraGram и AyuGram ещё не перенесён.
Сборка до добавления редактора/предпросмотра прошла 64 Android-проверки
в запуске [40317048308](https://github.com/wromlyy/WGram/actions/runs/40317048308).
Для новых экранов требуется отдельный прогон.

## Изменения

- На главном экране настроек остались ссылки на разделы: оформление,
  профиль, сообщения и приватность, дополнительные функции, плагины.
  Разделы открываются отдельными страницами. Удалены недоступные обработчики
  редактирования профиля, которые дублировали отдельный редактор.
- Переключатель рекламы отключает загрузку sponsored messages в чатах
  и sponsored peers в глобальном поиске. Обычные рекламные публикации
  каналов не распознаются как реклама.
- Номер телефона можно скрыть в заголовке настроек.
- Панель stories можно скрыть в основном списке и архиве.
- Экран может оставаться включённым, пока открыт чат.
- Кружочки можно начинать с задней камеры. В Camera2 предпочтение применяется
  при создании новой сессии; уже открытая сессия сохраняет выбранную камеру.
- Добавлен быстрый доступ к настройкам большой эмодзи, подсказок стикеров,
  встроенной камеры, остановки музыки при записи и прослушивания у уха.
- Добавлен Python 3.11 через Chaquopy 16.1 и управление локальными плагинами.
  Требуется **Android 7.0 / API 24**; версия 0.3 поддерживала API 23.
  Версия Telegram остаётся 13.1.1, код Android-сборки увеличен до 72409.

Реклама, скрытие номера/панели stories и удержание экрана разделены по ID
аккаунта. Камера и настройки SharedConfig общие для приложения.

## Общий каталог кастомок

Баннеры, снимки оформления профиля, отдельные эмодзи и наборы эмодзи/стикеров
можно отправлять в общий каталог через бота. После одобрения владельцем WGram
работа появляется в каталоге приложения. Есть просмотр, применение, «Мои работы»,
статусы модерации, удаление и страницы по 20 работ. В профиле добавлена ссылка
на каталог. Загрузка не выдаёт награды администратора.

При настройке `WGRAM_CATALOG_CHAT_ID` сервис также отправляет одобренные работы
в выбранную группу или канал. Код не создаёт и не запускает группу/хостинг.
Токен остаётся в окружении BotHost; всем клиентам нужен общий HTTPS-адрес.
[Команды и настройка](bot/README.md#общий-каталог-кастомок-04).

## Плагины

Настройки WGram → Плагины → Создать плагин или Добавить из файла.
Добавлен редактор Python с рабочим шаблоном, проверкой без выполнения,
сохранением черновиков, редактированием установленного кода и экспортом `.py`. После проверки метаданных
приложение показывает автора и описание. Импорт и обновление оставляют
плагин выключенным. Включение движка и запуск каждого плагина задаются
отдельно; удаление очищает файл и его настройки.

Плагины — доверенный исполняемый код с правами приложения, без песочницы.
Это собственный **WGram API 1**, а не реализация всего SDK exteraGram.
Файлы с требованиями к exteraGram SDK/app и внешними зависимостями явно
отклоняются. Xposed/Pine, произвольные хуки Java, pip, UI SDK и каталоги
плагинов exteraGram пока не поддерживаются.

[API и пример](PLUGINS.md). Готовый пример: [clean_links.py](plugins/clean_links.py).

## Сопоставление с другими клиентами

Сверка выполнена с открытыми Android-исходниками, а не с функциями
AyuGram Desktop. Проверенные ссылки и коммиты:

- [exteraGram main, 6f78031](https://github.com/exteraSquad/exteraGram/tree/6f78031aafd7f27e0dfaa31a207715569a6df1a2)
  и [ExteraConfig](https://github.com/exteraSquad/exteraGram/blob/6f78031aafd7f27e0dfaa31a207715569a6df1a2/TMessagesProj/src/main/java/com/exteragram/messenger/ExteraConfig.java).
- [AyuGram4A rewrite, 7013145](https://github.com/AyuGram/AyuGram4A/tree/7013145676d36d82ee13c02a89f72097b7490dcd)
  и [AyuConfig](https://github.com/AyuGram/AyuGram4A/blob/7013145676d36d82ee13c02a89f72097b7490dcd/TMessagesProj/src/main/java/com/radolyn/ayugram/AyuConfig.java).
- [Текущий публичный контракт SDK exteraGram](https://plugins.exteragram.app/docs/plugin-class).

Открытая Android-база обоих указанных репозиториев — Telegram 9.6.6.
README AyuGram отдельно указывает, что AyuHistoryHook и AyuMessageUtils
нужно реализовать самостоятельно. Современный SDK с документацией
для exteraGram 12.5.1+ нельзя получить слиянием этих старых исходников.

ненужных пользователю функций не был уточнён.
