# WGram 0.3 — в работе

- Удалённый обычный текст остаётся в основном чате с отметкой × у времени.
  Сохранение нужно заранее включить; секретные чаты, самоуничтожение,
  одноразовые и защищённые сообщения исключены. Хранение 7/30 дней,
  не более 2000 записей на таблицу. Темы форумов и ветки ответов пока не поддерживаются.
- Настройки и админка раскрывают блоки на одном экране. Новости: @WGramnews.
- Администратор 8226881959 может изменить текст ограничения WGram,
  запретить использование до отзыва, отправить предупреждение, выдать/отозвать значок.
  Панель ограничения содержит скачивание Telegram и обращение к администратору.
  Ограничение применяется клиентом; не изменяет доступ к аккаунту Telegram.
- Копирование профиля доступно в меню личного чата и требует подтверждения.
  Меняет реальные имя/фамилию, фото и описание в Telegram. Баннер, цвет и статус WGram
  копируются локально, публикация отдельная. Username и награды не копируются.
  Видеоаватар копируется как фото; описание ограничено реальным лимитом аккаунта.
- Четыре варианта формы текстовых пузырей с предпросмотром, включая угловатый
  вариант в духе Discord. Это оформление пузырей, а не полный интерфейс Discord.
- Публичная группа больше не используется. Общие профили и значки обслуживает
  Python-бот с HTTPS API и SQLite: [инструкция BotHost](bot/README.md).
  Баннер можно отправить боту в личку. Авторизация — одноразовая привязка через
  Telegram ID реального отправителя. В APK нет токена бота.

Статус: автоматические проверки исходников проходят. Сборка Android и проверки
на эмуляторе ещё выполняются. Вылет профилей пока не подтверждён исправленным.
Бот не развёрнут: необходим рабочий HTTPS-адрес и BOT_TOKEN на хостинге.

## Сравнение с другими модами

По официальным описаниям exteraGram и AyuGram от 25 октября 2026 года:

| Возможность | WGram 0.3 |
| --- | --- |
| Отдельные переключатели призрака, как у AyuGram | Есть; отправка и реакции могут раскрыть активность |
| История удалений и правок | Есть для обычного текста; без синхронизации истории между устройствами |
| Локальный Premium | Визуальное оформление; серверные лимиты не изменяются |
| Оформление интерфейса, как у exteraGram | Стекло и формы пузырей; полной системы тем Material You пока нет |
| Фильтры сообщений и исключения по чатам | Пока нет |
| Предупреждение перед открытием stories | Пока нет |
| Ускорение загрузок и новая камера exteraGram | Пока нет |

[AyuGram Android](https://docs.ayugram.one/android/),
