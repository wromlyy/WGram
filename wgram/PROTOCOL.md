# WGram emoji v1

В обычном Telegram-сообщении текст остаётся исходным Unicode-символом.
Для аккаунта без настоящего Premium WGram преобразует выбранный custom
emoji в стандартную `messageEntityTextUrl`:

```
text: "hi 😀!"
entity.offset: 3
entity.length: 2
entity.url: "https://t.me/WGramnews?wgram_emoji=v1_5368324170671202286"
```

Offsets измеряются в UTF-16, как в Telegram API и Java. ID передаётся
десятичной строкой без потери точности 64-битного числа. Нового backend нет.
Обычный клиент показывает исходный символ со ссылкой, WGram распознаёт
ссылку и создаёт AnimatedEmojiSpan через существующий механизм Telegram.
Ссылка не открывается автоматически и не содержит внешнего сервера.

При отображении создаётся копия списка entities; полученное сообщение
не переписывается. В версии 0.1 распознавание полученных WGram-эмодзи
всегда активно; настройка «Эмодзи WGram» управляет выбором и отправкой.
Профили и значки передаются отдельно через подключённый HTTPS-сервис бота.

Поддерживаемые точки: обычный текст, подписи, отправка, редактирование
текста и подписи. Для настоящего Premium сохраняется родной Telegram
формат. Для секретных чатов модовый способ отправки отключён.
Реакции, истории, опросы и оформление профилей другим пользователям
в эту версию протокола не входят.

Ссылки с неизвестной версией, некорректным ID, переполнением, выходом
за пределы текста и разрывом surrogate pair остаются обычными ссылками.
Количество анимированных spans ограничивает существующий код Telegram.

Старые `wgram://emoji/v1/ID` читаются, но новые сообщения используют HTTPS.
Пока не проверено с двумя реальными аккаунтами: передача HTTPS text-link сущностей,
синхронизация на другом устройстве, редактирование с серверным ответом,
и корректное отображение во всех официальных клиентах.
При несовместимости нужно сменить транспорт до выпуска версии.

Изменение транспорта: [TDLib LinkManager](https://github.com/tdlib/td/blob/master/td/telegram/LinkManager.cpp) распознаёт HTTP(S), tg, ton и tonsite; нестандартный wgram-протокол не подходит для новых ссылок.
