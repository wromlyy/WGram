# Плагины WGram API 1

Плагин — один UTF-8 Python-файл до 1 МиБ. Расширения `.py` и `.plugin`
допускаются в файловом выборе; ZIP, DEX/JAR и pip-зависимости не поддерживаются.
Движок запускает доверенный код с доступом к Python/Java и правами WGram.
Установленные плагины и их настройки общие для аккаунтов.

```python
from base_plugin import BasePlugin, HookResult, HookStrategy

__id__ = "hello_world"
__name__ = "Hello World"
__description__ = "Добавляет подпись к отправляемому тексту"
__author__ = "Your Name"
__version__ = "1.0"
__wgram_api__ = 1

class HelloWorldPlugin(BasePlugin):
    def on_plugin_load(self):
        self.add_on_send_message_hook(priority=0)

    def on_send_message_hook(self, account, params):
        params.message += " — sent from WGram"
        return HookResult(strategy=HookStrategy.MODIFY, params=params)
```

Обязательные метаданные: `__id__` (2–32 латинские буквы, цифры, `_`, `-`,
начинается с буквы) и `__name__`. Метаданные читаются AST без выполнения
модуля и должны быть обычными константами. Ровно один класс в файле
должен наследоваться от BasePlugin.

`on_plugin_load` вызывается при включении или восстановлении включённого
плагина при запуске приложения. `on_plugin_unload` вызывается при отключении,
обновлении, удалении и выключении движка. Завершение процесса Android
не гарантирует вызов unload; обязательные данные нужно сохранять сразу.

`add_on_send_message_hook(priority=0)` включает обработчик отправки;
сначала вызывается больший priority, затем сортировка по ID плагина.
Обработчик получает реальный номер слота аккаунта `account` и копию
текстовых параметров: `params.message` и 64-битный `params.peer`.
Нельзя подменить адресата изменением `params.peer`.

- `DEFAULT`/`None`: оставить текст без изменений.
- `CANCEL`: отменить отправку.
- `MODIFY`: использовать `HookResult.params.message`, продолжить обработку.
- `MODIFY_FINAL`: использовать текст и завершить обработку.

Изменённый текст должен содержать 1–4096 кодовых единиц UTF-16. Старые
entities и веб-превью удаляются, поскольку их смещения/URL относятся к
исходному тексту. Обычная отправка заново определит предварительный просмотр.

Обрабатываются только новые обычные текстовые сообщения: без секретных
чатов, TTL, подписей к медиа, пересылок, повторов, правок и служебных запросов.
Хук вызывается в SendMessagesHelper до формирования сообщения.
Отмена показывает уведомление; исходный текст автоматически в поле ввода
не восстанавливается. Командные плагины могут использовать CANCEL для
перехвата собственных команд.

`self.get_setting(key, default=None)` и `self.set_setting(key, value)` хранят
JSON-значения в приватном каталоге приложения. Если нужны настройки для
каждого аккаунта, используй ключи с ID пользователя, а не только слотом
аккаунта, который может быть повторно использован после выхода.
`self.logger` — обычный Python logger; `self.log(message)` — сокращение.

## Создание и редактирование в приложении

Настройки WGram → Плагины → Создать плагин. Редактор открывает рабочий
шаблон с уникальным `__id__`. Можно изменить код и нажать «Проверить»:
проверяются синтаксис Python и метаданные без выполнения модуля.
Обработчики и импорты проверяются уже при явном включении.

«Сохранить» после подтверждения устанавливает код **выключенным**.
В меню установленного плагина есть «Редактировать код». При редактировании
ID должен сохраняться; для другого ID создавай новый плагин.
Настройки плагина сохраняются при обновлении, а работающая версия выгружается.
«Экспорт» сохраняет текущий текст в `.py` через системный выбор файла;
проверка не обязательна, поэтому можно экспортировать незаконченный код.

Черновик автоматически сохраняется на устройстве через 500 мс после правки,
а также при уходе с экрана. Для нового плагина есть один черновик, для каждого
установленного — отдельный. Повторное открытие восстанавливает его; успешная
установка удаляет черновик. Проверка, сохранение и экспорт не включают движок
и не запускают написанный код. Готовые файлы можно передавать другим пользователям.

## Ошибки и восстановление

Исключение при загрузке отключает плагин и отображает причину в списке.
Исключение при отправке отключает плагин и отменяет текущую отправку.
После обновления плагин всегда выключен, даже если старая версия работала.
SHA-256 проверяется между подтверждением установки и копированием, а также
при загрузке установленного файла. Он контролирует целостность, но не
подтверждает личность автора.

Перед выполнением callback записывается маркер. Если процесс оборвался
внутри плагина, при следующем запуске Python отключает все ранее активные
плагины. Включать их нужно вручную. Java ждёт обработчик отправки максимум
1 секунду; при превышении выключает движок и отменяет отправку.
Python-код может проигнорировать прерывание: для освобождения зависшего
потока потребуется перезапуск приложения. Главный поток не ждёт его бессрочно.

## Совместимость

Названия BasePlugin/HookResult и основных обработчиков похожи на API
exteraGram, но WGram API 1 реализует только описанную здесь часть.
Требования `__sdk_version__`, `__app_version__`, `__min_version__` и
непустой `__requirements__` отклоняются с понятной ошибкой до запуска.
Автоматическое превращение произвольного exteraGram-плагина в WGram-плагин
не поддерживается. Произвольные Java-хуки, сетевые хуки, create_settings,
меню и пакеты `ui.*`, `client_utils`, `android_utils` пока не реализованы.

[Пример очистки ссылок](plugins/clean_links.py) можно скачать из репозитория,
импортировать в приложении и отдельно включить.

## Проверки

```sh
python3 -m unittest discover -s wgram/tests -p 'test_*.py' -v
```

Проверяются отсутствие выполнения при импорте, путь/лимиты/метаданные,
несовместимые SDK, SHA-256, явное включение, жизненный цикл, восстановление
после сбоя, обновление/удаление, настройки, ошибки отправки, приоритеты,
64-битные ID, UTF-16, поставляемый пример, шаблон редактора, сохранение
исходника, проверка без запуска и сохранение идентичности плагина.
Android instrumentation отдельно проверяет реальный Python runtime,
загрузку/выгрузку, отправочный мост, entities и исключение секретных чатов.
