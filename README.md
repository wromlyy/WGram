# WGram · Android

В ветке `wgram-0.4-plugins` разрабатывается **WGram 0.4**: отдельные страницы
настроек, дополнительные переключатели и Python-плагины WGram API 1.
[Изменения и состояние переноса exteraGram/AyuGram](wgram/FEATURES-0.4.md) ·
[Как добавить или написать плагин](wgram/PLUGINS.md).
Новая версия требует Android 7.0+. Полная совместимость со всеми функциями
и плагинами других клиентов пока не реализована.
Ниже — опубликованная версия 0.3 и результаты её проверок.

Мод на официальных исходниках Telegram Android 13.1.1.
**[Скачать WGram 0.3 APK](https://github.com/wromlyy/WGram/releases/download/v0.3/WGram.apk).**
Пройдены сборка и 52 проверки экранов/поведения на Android 14.
[Результаты и ограничения проверки](wgram/VALIDATION.md).
Репозиторий приватный: для скачивания нужен вход в GitHub с доступом к нему.

В 0.3 добавлены:

- удалённый обычный текст прямо в чате с отметкой × у времени;
- настройки и админка с раскрывающимися блоками на одном экране;
- изменяемый текст ограничения WGram до отзыва администратором;
- копирование имени, фото, описания и оформления из меню личного чата
  с подтверждением изменения своего профиля;
- четыре формы пузырей с предпросмотром и канал @WGramnews;
- бот для общего оформления и значков вместо публичной группы;
- одно меню WGram в профиле и до трёх наград рядом с именем
  в профиле, списке чатов и заголовке личного чата;
- исправления вылета профиля, измерения значков и сохранения истории,
  HTTPS-формат отправки эмодзи с поддержкой прежних сообщений.

Также есть отдельные настройки WGram, оформление в стиле Liquid Glass
с пресетами и лёгким режимом, баннеры профиля, визуальный Premium,
эмодзи-статус, ID пользователя, специальные значки, история правок,
отдельные переключатели призрака для чтения, набора, онлайна и stories,
подтверждение звонков и секунды у сообщений.
Админка предназначена для Telegram-аккаунта **8226881959**.

[Скачать проект бота для BotHost](https://github.com/wromlyy/WGram/releases/download/v0.3/WGramBot.zip).
Он готов к загрузке, но **сервис ещё не запущен на хостинге**.
Токен хранится только в переменной `BOT_TOKEN` на BotHost. Затем в WGram
вводится HTTPS-адрес сервиса и подтверждается привязка в личке с ботом.
Баннер можно отправить боту фотографией. Публичная группа не используется.
[Инструкция бота](wgram/bot/README.md).

Оформление и экспериментальные эмодзи рассчитаны на WGram.
Серверные права Premium и лимиты Telegram не изменяются.
Обычный Telegram получает запасной символ эмодзи со ссылкой.
Стекло поддерживает лёгкий Canvas-режим на старых устройствах;
преломление доступно с Android 13. Полное совпадение с iPhone
и оформление каждой поверхности ещё не реализованы.

История по умолчанию выключена. Она сохраняет полученный после включения
обычный текст и подписи к медиа; сами файлы не сохраняются.
Секретные, исчезающие, одноразовые и защищённые сообщения исключены.
Темы форумов и ветки ответов пока не поддерживаются.
Данные разделены по аккаунтам и очищаются при выключении функции или выходе.
Призрак не обеспечивает полной невидимости: отправка сообщения и реакции
могут раскрыть активность из-за поведения сервера Telegram.

Реальный вход, копирование профиля и обмен между двумя аккаунтами
требуют проверки на устройствах. Firebase в этой сборке выключен:
фоновые уведомления могут задерживаться.
