# WGram · Android

Мод на официальных исходниках Telegram Android 13.1.1.
Версия **0.2, тестовая**. [Скачать APK в ZIP](https://github.com/wromlyy/WGram/actions/runs/40212509751/artifacts/12606760732).
Репозиторий приватный: нужен вход в GitHub с доступом к нему.
Распакуйте архив и установите `app.apk`. Android 6.0+, четыре ABI, 109.2 МБ.
Локальный готовый файл: `~/WGram.apk`.

Добавлены:

- отдельные настройки WGram, Liquid Glass с пресетами, оттенками, бликами,
  контуром, тенями, плотностью, преломлением и живым предпросмотром;
- редактор профиля: баннер вместо цвета, эмодзи-статус без Premium,
  локальный Premium и явная публикация оформления для других WGram;
- Telegram ID в профилях, копирование ID и обновление общего оформления;
- админка аккаунта **8226881959**: закрываемые шуточные баны, предупреждения,
  отмена, причины, сроки, предпросмотр и журнал отправок;
- создание специальных значков с названием, описанием и эмодзи,
  шаблоны, выдача и отзыв; значок заменяет статус в профиле WGram;
- локальная история текста удалённых сообщений и предыдущих правок:
  поиск, фильтры, очистка и срок хранения 7/30 дней;
- отдельные переключатели призрака: чтение, набор, онлайн и просмотр stories;
- подтверждение личных звонков, секунды у времени сообщений;
- экспериментальные премиум-эмодзи в сообщениях между пользователями WGram;
- собственные название, package и иконки W, постоянная подпись обновлений.

Для общего оформления администратор должен один раз войти аккаунтом
**8226881959** и нажать **Настройки WGram → Админка → Создать каталог**.
Каталог — публичная Telegram-группа `@wgram_profiles_8226881959`.
Публикация баннеров и значков требует явного подтверждения.
Профили принимаются только от их владельцев, значки — от администратора.
Пересланные записи не меняют чужие профили и не вызывают плашки.

Стекло использует Canvas на старых/слабых устройствах и поддерживаемый
рендерер Telegram на новых; преломление доступно с Android 13.
Это собственное оформление в стиле Liquid Glass; совпадение с iPhone
и поддержка каждой поверхности интерфейса не гарантируются.

История по умолчанию выключена и сохраняет только текст сообщений,
уже полученных после включения. Секретные, исчезающие и защищённые сообщения,
а также сами медиа исключены. Данные разделены по аккаунтам и очищаются
при выключении функции или выходе. Серверные Premium-права не изменяются.
Обычный Telegram получает запасной символ эмодзи со ссылкой.
Призрак не делает аккаунт полностью невидимым и противоречит
[условиям Telegram API](https://core.telegram.org/api/terms).

106 проверок логики, Android-компиляция и упаковка APK прошли;
подпись v1/v2 и постоянный сертификат WGram проверены.
**Запуск на телефоне и обмен между двумя аккаунтами пока не проверены.**
Firebase в этой сборке выключен: фоновые уведомления могут задерживаться.
